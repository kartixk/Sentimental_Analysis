# Sentimental_Analysis
This project is a Sentiment Analysis system built using Deep Learning (Bidirectional LSTM) and deployed as a Flask web application. It classifies user-input text into Negative, Neutral, or Positive sentiments with confidence scores.


## Dataset
The dataset (`train.csv`) is not included in this repository due to size and licensing reasons.

Expected columns:
- text
- sentiment (negative, neutral, positive)

You can place your dataset in the project root as `train.csv`.
